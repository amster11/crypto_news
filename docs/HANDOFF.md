# Передача проекта в новый чат

## Проект
Премиальный корпоративный сайт юридических и бизнес-услуг (Москва): регистрация ООО/АО/ИП, юридические адреса от собственников, сопровождение налоговых проверок, ликвидация ООО/ИП, консалтинг.

- Репозиторий: https://github.com/amster11/crypto_news
- Рабочая ветка: `claude/laughing-turing-ztk7qj` (PR не создавался)
- Стек: Next.js 16 (App Router, Turbopack) · React 19 · TypeScript · Tailwind CSS 4 · lucide-react. Без Framer Motion и UI-библиотек.
- Проверки: `npm run lint`, `npm run build` — проходят.
- Важно: в `AGENTS.md` — Next.js 16 отличается от старых версий, сверяться с `node_modules/next/dist/docs/`.

## Источники требований
1. Первое ТЗ (текстом в чате): стиль Premium Corporate / Legal, палитра Deep Navy #0B1628, Dark Navy #111D31, Off-White #F5F3EF, Gold #B89A62 (только акцент), Text #172033, Muted #697386, Border #DDE1E7; шрифты Cormorant Garamond + Manrope; главный CTA «Получить консультацию»; SEO, a11y, адаптив от 320px, prefers-reduced-motion; не выдумывать факты — плейсхолдеры в квадратных скобках.
2. Рукописное ТЗ заказчика — фото и расшифровка в `docs/tz/` (приоритетнее первого по услугам, ценам и контенту).

## Принятые решения
- Язык: только русский. URL — транслит. Валюта — ₽. Город — Москва.
- Услуги: 01 Регистрация ООО, АО и ИП · 02 Юридические адреса · 03 Налоговые проверки (только налоговые, без банковских) · 04 Ликвидация · 05 Консалтинг (короткая страница, тексты написаны нами — требуют проверки).
- Убраны «Бизнес под ключ», «Сопутствующие услуги», пакеты Basic/Business/Full.
- Форма «Обратный звонок»: имя*, телефон*, почта (необязательно), услуга (select с группами), сообщение, согласие*. POST `/api/lead` → `deliverLead()` в `src/lib/leads.ts` (без `LEAD_WEBHOOK_URL` — только лог сервера). Кнопки «Заказать» (`OrderButton`) скроллят к форме на текущей странице и подставляют услугу.
- Контакты: звонок, Telegram, почта, MAX (иконки).
- Изображения: Unsplash через next/image; при ошибке загрузки — navy-заглушка (`Photo`).
- Хостинг: VPS (Ubuntu + Node 22 + PM2 + Nginx + Certbot). Статический экспорт невозможен из-за API формы.

## Где менять контент
- `src/config/site.ts` — название, телефон, почта, Telegram, MAX, адрес, реквизиты.
- `src/data/services.ts` — услуги, позиции прайса и цены, преимущества, этапы, FAQ-ссылки.
- `src/data/pricing.ts` — карточки цен на главной (генерируются из services), примечания.
- `src/data/faq.ts`, `src/data/content.ts` (hero, trust bar, «Наши преимущества», about, цифры), `src/data/testimonials.ts`, `src/data/images.ts`, `src/data/legal.ts`, `src/data/navigation.ts`.
- Плейсхолдеры `[...]` автоматически исключаются из ссылок и Schema.org (`isFilled()` в `src/lib/utils.ts`).

## Открытые вопросы к заказчику
1. Ликвидация ООО без отчётности — 45 000 или 35 000 ₽? (в ТЗ цифра исправлена; сейчас 45 000)
2. Что значит «гарантия собственника» (налоговые проверки)? Пока не выводится.
3. «Переоформление по ОКП» (покупка компании) — расшифровка? Пока не выводится.
4. Контакты: телефон, почта, адрес, Telegram, MAX, часы работы.
5. Название компании (сейчас «Company Name» / «[Название компании]»), логотип, сколько лет опыта.
6. Формулировка «Работаем над уменьшением сумм штрафов, налогов и пени» — устраивает?
7. Тексты страницы «Консалтинг» — проверить.
8. FAQ без ответа: срок регистрации; бесплатна ли консультация перед заказом.
9. Отзывы, цифры в «О компании», фото — заглушки до реальных данных.
10. Тексты политики конфиденциальности и условий — шаблон, нужен юрист.
